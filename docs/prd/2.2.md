# PRD: opencode-harness 2.2.0

**Goal** — `install.sh --dry-run` показывает план установки и ничего не
записывает; устаревший совет «выйди из opencode и запусти заново» заменён на
`/reload`.

**Non-goals**

- `--dry-run` для `uninstall.sh`.
- Полный unified diff содержимого: план печатает файлы и изменения ключей
  `opencode.json`.

**User story** — Как пользователь, я хочу увидеть, что установщик сделает с
`~/.config/opencode`, до того как он это сделает, и не получить новый
`backup-*` ради любопытства.

**Acceptance criteria**

1. `--dry-run` на пустом каталоге: код `0`, каталог остался пустым, в выводе
   `создать AGENTS.md` и `создать opencode.json`.
2. `--dry-run` на существующем конфиге: код `0`, хэши файлов до и после равны,
   новых `backup-*` нет, в выводе `обновить opencode.json` и `+permissions`,
   `mcp` не удаляется, выбранная модель не меняется.
3. Битый `opencode.json`: код `1`, причина названа, файл не тронут, ничего не
   создано. Валидация переехала в начало скрипта.
4. Версия ниже минимума: код `1`, ничего не записано, в том числе в `--dry-run`.
5. Неизвестный флаг: код `64`, подсказка `--dry-run`.
6. `install.sh` и README не говорят «запусти заново», упоминают `/reload`.

**Решение по устройству**

План строится прогоном настоящего `install.sh` в staging-копии: `mktemp -d`,
копия управляемых путей (`AGENTS.md`, `opencode.json`, `agent/`, `command/`,
`skill/`), установка в копию всей копии, затем python-дифф. План не может
разойтись с реальным поведением, потому что это и есть реальное поведение.
`backup-*` и `harness-installed.txt` из диффа исключены.

**Risks**

- Staging копирует только управляемые пути: если установка начнёт трогать
  что-то ещё, дифф этого не увидит. Тест на хэши реального каталога страхует.
- Ранняя валидация JSON меняет реальную установку: при битом конфиге больше нет
  частично скопированных файлов.

**Sources and assumptions**

- Прочитано: `install.sh`, `tests/install.bats.sh`, `tests/docs.bats.sh`,
  `README.md`, `CHANGELOG.md`, issue #2 и #3.
- Документация opencode v2: конфиг, агенты, команды и скиллы перезагружаются
  без рестарта, принудительно — `/reload`.
- Проверено вживую: `./install.sh --dry-run` на рабочем конфиге, отсутствие
  новых `backup-*`.
